## 0. 운영 원칙

- 한 케이스 = 화자 / 입력 / 기대 도구 흐름 / 합격 기준 / 평가층. 실행 결과는 회차별 `results/` 기록(자동 실행 스크립트는 G1 준비 시 — ROADMAP 증설 예약).
- **36케이스 = 구 30 구조 유지 + 실패·오남용 확장 6** (2026-08-03 결정 — PROGRESS 결정 기록). 쓰기 확인 3→8, 오류/점검 1 신설. 구 케이스의 분류·비중은 감축 없이 그대로다. 인젝션(SC-24)·자격증명(SC-25)은 구 C-04·G-03 자리를 승계해 증설이 없다.
- **기준일 2026-08 고정**(유저_시나리오 §1과 동일 — 시드의 진행중 프로젝트가 8월을 관통). 실행 환경은 시스템 프롬프트 날짜 주입(구현 노트 §3)으로 기준일을 고정한다. "이번 달"=2026-08, "다음 달"=2026-09.
- **화자는 케이스별 고정** — 페르소나는 `docs/유저_시나리오.md` §2의 시드 실존 인물을 그대로 쓴다(재정의 없음). 같은 입력도 화자 가시성에 따라 기대값이 다르기 때문(구 문서의 양시온 등 비실존 인물은 폐기).
