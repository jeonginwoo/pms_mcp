- **원장은 여전히 한 벌이다** — 채점층도 기대값을 복제하지 않는다. 두 층의 경계가 그
  규율이다:
  - **규칙층**(`RuleGrader`) — 기대값 없이 물증만으로 서는 판정만: 수치 출처 대조(답의
    수치가 그 대화의 도구 결과에 있는가 = F1) · 2단계 확인 왕복과 감사 행 대조(F3) ·
    카탈로그 밖 도구(F5) · 길이(F8) · 근거 시점 표기(F9).
  - **Judge층**(`Judge`, `claude-opus-5`) — 이 문서의 **해당 행과 절 머리표를 그대로**
    루브릭으로 받아 개수·인물 일치, 거절 여부, 톤·유용성을 판정한다. 기준 모델
    (`claude-sonnet-5`)과 다른 모델인 것은 자기채점 편향 회피다(PRD-host §6-3 "편향 주의").
- **못 보는 것은 못 봤다고 적는다**: 도구를 불렀는데 결과가 기록에 없으면 규칙층은
  F1을 매기지 않고 `OBS 확인 불가`로 남긴다. 관측 공백이 치명으로 둔갑하면 "치명 0건"
  기준을 영원히 못 넘는다.
- **경미는 불합격이 아니다**(F8·F9 — PRD-host §6-2 모니터링 등급). 경미를 불합격으로
  세면 게이트 수치가 기준과 달라진다.
- **채점 기록**: `grades.jsonl`(기계 판)과 `grade.md`(사람 판 — 합격률·치명 건수·케이스별
  사유). 이것은 게이트 판정의 **입력**이지 통과 선언이 아니다 — 승인은 사람이 한다.
